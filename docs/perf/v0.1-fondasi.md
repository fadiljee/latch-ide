Pengukuran dilakukan pada Linux x86_64 (`7.1.5+kali-amd64`, Rust `1.100.0`) menggunakan skrip otomatis [`scripts/check-binary.sh`](../../scripts/check-binary.sh), [`scripts/bench-rss.sh`](../../scripts/bench-rss.sh), dan [`web/scripts/check-bundle-size.mjs`](../../web/scripts/check-bundle-size.mjs).

## Catatan Lingkungan & Reproduksibilitas

- Build musl statis (`x86_64-unknown-linux-musl`) memerlukan paket `musl-tools` (`musl-gcc` + header musl) agar SQLite `bundled` tertaut statis murni tanpa simbol glibc `*64`. Job CI `.github/workflows/ci.yml` memasang `musl-tools` dan memverifikasi `./scripts/check-binary.sh --require-musl`.
- Di mesin lokal tanpa `musl-tools`, `./scripts/check-binary.sh` memverifikasi ukuran binary rilis host dan `./scripts/bench-rss.sh` memverifikasi anggaran RAM daemon secara langsung.
